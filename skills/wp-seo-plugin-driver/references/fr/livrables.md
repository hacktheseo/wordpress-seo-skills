# Livrables en français

À charger quand l'utilisateur écrit en français.

## Vocabulaire

| À dire | À éviter |
|---|---|
| extension SEO | « plugin » dans un livrable client (acceptable entre techniciens) |
| titre SEO, méta description | « meta title » |
| balise canonique | « canonical » seul |
| indexée, non indexée (noindex) | « désindexée » quand la page n'a jamais été indexée |
| ce que la page affiche | « ce qui est en base » |

## Verdicts types

- « 3 pages sur 6 ont perdu un élément qui coûte du trafic »
- « Les 38 nouvelles descriptions s'affichent sur les 38 pages »
- « Deux extensions SEO écrivent en même temps dans les pages : titres et données structurées en double »

## Le message avant d'appliquer

> Voici les 12 modifications prévues, page par page, et le fichier qui les
> enverra. Rien n'est parti. Je commence par une seule page, je vérifie
> qu'elle affiche bien le changement, puis j'envoie le reste si vous validez.

## Le message après

> Les 12 modifications sont en ligne et vérifiées sur les pages elles-mêmes,
> pas seulement dans l'administration. Le rapport joint montre l'avant et
> l'après. Le mot de passe d'application créé pour l'occasion peut être
> révoqué dès maintenant.

Jamais de promesse de position : un titre ou une description change ce que
voit l'internaute dans les résultats, pas le classement.
